**푸리에급수 프레임 구현**

사진의 윤곽선을 복소 푸리에 급수로 학습한 뒤, 회전하는 원(에피사이클)이 그림을 그려 나가는 과정을 프레임 단위로 모두 보여주는 웹 페이지입니다. 설치할 것이 없습니다.

## 실행

`src/index.html` 을 브라우저(Chrome, Edge 등)로 열면 됩니다.

## 동작 순서

1. **사진 선택 · 윤곽선 추출** — 사진을 불러오면(파일 선택, 끌어다 놓기, Ctrl+V) 최대 360px로 줄인 뒤 Canny 방식(가우시안 블러 → Sobel → 비최대 억제 → 히스테리시스)으로 에지를 찾고, 점을 샘플링해 최근접 이웃 순서로 한 붓 경로를 만듭니다.
2. **학습** — 경로의 점 `z_n = x_n + i·y_n` (N개)에 이산 푸리에 변환을 적용해 계수 `c_k = (1/N) Σ z_n e^{-i2πkn/N}` 를 구합니다.
3. **프레임 재생** — `z(t) = Σ c_k e^{i2πkt}` 를 진폭이 큰 항부터 원으로 이어 붙여 그립니다. 프레임 슬라이더, 속도, 사용할 항 개수, 총 프레임 수를 조절할 수 있습니다.
4. **전체 프레임** — 모든 프레임을 썸네일로 한 번에 보여주고, 한 장짜리 프레임 시트 PNG로 저장할 수 있습니다.
5. **수렴 과정** — 항을 1, 2, 5, 10 … 개 사용했을 때의 근사 결과를 나란히 보여줍니다.

## 파일

- `src/index.html`, `src/style.css` — 화면
- `src/js/edge.js` — 에지 검출, 점 샘플링, 경로 정렬
- `src/js/fourier.js` — DFT(학습)와 급수 복원
- `src/js/app.js` — 재생, 프레임 갤러리, 저장
